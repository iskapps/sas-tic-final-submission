# SAS Final-Stage Submission — Hardi Fichardt

Live page for the Elementary School Technology & Innovation Coordinator performance tasks.

## Update Task 1 video

Edit `config.js`:

```js
videoEmbedUrl: "https://www.youtube.com/embed/YOUR_VIDEO_ID",
```

Or place an MP4 in `assets/` and set `videoFile: "assets/your-file.mp4"`.

## Local preview

Open `index.html` in a browser, or run:

```bash
npx --yes serve .
```
