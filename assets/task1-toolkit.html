Purposeful technology in elementary inquiry

Research → Evaluate → Communicate — without drowning learners in screens

← Back to submission

Outcomes

  • Choose tech only when it improves research, evaluation, or communication
  • Support colleagues along Explore → Try → Embed

Three filters

  1. Learning goal first — What should students understand or do?
  2. Access — Does it widen participation, including multilingual learners and learning support?
  3. Sustainability — Can we support this without burning teacher or IT time?

Inquiry moments

  • Research: curated texts first; shared collection only if it reduces chaotic search
  • Evaluate: partner talk + sort; optional checklist or voice note for why
  • Communicate: oral/written first; multimedia for audience or accessibility

Tech only if it helps students research, evaluate, or communicate — otherwise leave it out.
